# Research article materials

This repository collects data, visualizations and supporting materials for research articles. Each article has its own directory and README with its data sources, file descriptions and usage instructions.

## Article index

| Article / project | Directory | Available materials |
|---|---|---|
| UAV–UGV cooperative rescue under incomplete task information | [UAV-UGV-LMRR](UAV-UGV-LMRR/) | Urban geometry, animated case replays, frozen scenes and an interactive MATLAB viewer |

New articles can be added as separate project directories and listed in this index. Article-specific links should point to the corresponding directory.

## Data attribution

Data provenance, original-source terms and reproduction instructions are documented in each article directory.
